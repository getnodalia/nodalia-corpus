# nodalia-corpus

Test files that Nodalia's apps use to check themselves against real-looking input. Every file here
is either generated by a Nodalia tool or comes from an open source with its licence noted, and
every file says where it came from (see `PROVENANCE.md`). Nothing here comes from another
company's product or repository.

Apps never commit these files themselves. They fetch this repository pinned by commit and check
each file's SHA-256, or read a local clone, and **their tests skip with a clear message when the
corpus is not present** (a missing corpus is a failure only when the app's `*_REQUIRED=1`
variable is set, as in CI).

## Layout

| Folder | For | What is in it |
|---|---|---|
| `forja/` | Forja (`cargo xtask corpus`, `FORJA_CORPUS_DIR`) | DXF drawings generated by `tools/generate-forja.py`, with `SHA256SUMS` |
| `real/` | any app | Real files made by third-party programs (Photoshop, AutoCAD, After Effects…), added by the maintainer with provenance, see `real/README.md` |
| `tools/` | maintainers | Generators; each one regenerates its folder byte for byte |

More folders (`pulso/`, `lienzo/`, …) appear when an app's own tools can generate files for them.

## Rules for adding files

1. **Say where it came from.** Add a row to `PROVENANCE.md` in the same change: path, how it was
   made (tool and version, or source URL), author, licence.
2. **Licence.** Generated files are CC0-1.0. Anything else must carry a licence on Foundation's
   allowlist and keep its licence text next to it.
3. **No other company's files.** Never copy a corpus out of another organisation's repository or
   product. A file made by a person with a licensed copy of a program may go in `real/` only when
   that person says it is theirs to share.
4. **Small and honest.** Keep files small. A generated file stays reproducible from `tools/`.
5. **Keep sums.** Each folder that apps pin has a `SHA256SUMS` (`sha256sum * > SHA256SUMS`).
   Apps copy those lines into their own lock file, so a changed corpus cannot vouch for itself.

Pinning example: take the commit of this repository, then put the commit and the `SHA256SUMS`
lines in the app's lock file.
