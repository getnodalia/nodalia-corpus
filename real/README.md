# Real oracles

Files made by programs other than Nodalia's (a Photoshop PSD, an AutoCAD DWG, an After Effects
project, a GIMP XCF…) are useful because they show what other programs really write. They are
optional: the apps' tests skip when a file is absent.

To add one, put it under `real/<app>/<program>/` and add a row to `PROVENANCE.md` with:

- **Made with:** the program and its version, on a machine with a licence for it.
- **By:** the person who made the file and says it is theirs to share.
- **Content:** what is in it (a synthetic document, never client work, never personal data).
- **Licence:** CC0-1.0, or the licence its author chose from Foundation's allowlist.

Never add: files from another organisation's corpus or repository, files with personal or client
data, files whose maker did not make them.
